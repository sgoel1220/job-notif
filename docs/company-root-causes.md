## Root-cause patterns

- Missing mappings, not missing adapters: Workday CrowdStrike/Red Hat/SUSE/insightsoftware URLs were present on official pages; parse the real tenant/shard/site and POST the existing CXS API.
- Incomplete discovery: embedded Greenhouse JS, Ashby embeds, and API-only Lever links were missed by simple anchor extraction.
- Wrong paths and stale platforms: Skillshare needs the implemented Workable v1 widget API, not a guessed v3 endpoint. Cerebral currently links Greenhouse boards whose main candidate returns 404; its old empty Workable board must not be substituted.
- Empty results are not automatically valid: Pagos is officially linked and valid-empty; Deel has active jobs.deel.com postings conflicting with an empty legacy Ashby feed.
- Adapter gaps: Rippling (AgentSync/Chess.com), Pinpoint (SafetyWing), Breezy (Prufrock Ventures), and Jibe/iCIMS/custom sites require separately verified feed contracts.
- Employer identity matters: Obsidian, Loft, DataChain, Superhuman Docs and parent/acquired brands cannot be safely mapped from a bare name alone.
- Access failures differ from lack of jobs: record actual 403/406/429, DNS and 404 failures; browser inspection remains necessary for dynamic careers widgets.

These are observed research outcomes, not a claim that every remaining employer has a proven root cause. `unresolved` explicitly means current evidence remains insufficient. Acquired-brand findings require care before mapping parent feeds, which may already be enabled.
